Use

Command What it does
skdeck Open the full-screen UI
skdeck add <github-url> Import Skills from GitHub
skdeck use [deck] Preview, then apply a Deck
skdeck remove [deck] Preview, then remove a Deck
skdeck list List the Library and Decks

add, use, and remove need a TTY. use and remove take -p, --project and default to the current directory.

Safety

Applying a Deck always shows a plan first. Unmanaged Skills are left alone.
