Concepts

Three objects. Everything else is a command around them.

01

Library

Locally imported Skill revisions. Each one is pinned to its source commit and a content hash, so a Deck never silently drifts.

02

Deck

A named, reusable selection of Library revisions. Build a frontend hand, a review hand, a company-standard hand — then reuse it.

03

Project

The directory that receives a Deck. Managed Skills are written under .agents/skills, with ownership recorded in .agents/skdeck.lock.

Workflow

Import, compose, preview, apply. The full-screen UI is the default; the commands below are the same path without the TTY.

add

Import from GitHub

Point at a repository, a skills directory, or a single Skill URL. skdeck discovers complete Skills and imports the ones you select.

skdeck add https://github.com/owner/repo/tree/main/skills
decks

Compose a Deck

Open the interface, pick Library entries, and add them to a new or existing Deck. Revisions stay pinned after you add them.

skdeck
use

Preview, then apply

Applying a Deck always shows the plan first. Confirm to write Skills into the project; cancel leaves the tree unchanged.

skdeck use frontend --project ./my-project
remove

Inspect and remove

List local Decks and Library entries, or preview a removal before uninstalling a Deck from a project.

skdeck list
skdeck remove frontend --project ./my-project

Safety

skdeck manages user files and untrusted GitHub content. The apply path is a plan, not a silent copy.

Apply “frontend”?

  1. ADD anti-ui-slop — .agents/skills/anti-ui-slop
  2. ADD ui-design — .agents/skills/ui-design
  3. KEEP terminal-ui — already this revision
  4. CONFLICT review-notes — unmanaged local Skill

Resolve conflicts before continuing · Esc cancel

Unmanaged Skill directories are never overwritten. Managed Skills with local modifications are refused. Shared revisions track ownership across Decks. Catalog and lock writes are atomic. Deck entries pin to content-addressed, immutable Library revisions.

Commands

Running skdeck with no command opens the full-screen interface. add, use, and remove are interactive and require a TTY.

Command What it does
skdeck Open the full-screen interface
skdeck add <github-url> Discover and import Skills from GitHub
skdeck use [deck] Preview and apply a Deck
skdeck remove [deck] Preview and remove an installed Deck
skdeck list List the Library and Decks
skdeck --help Show all commands and options

use and remove accept -p, --project <path> and default to the current directory. Catalog data lives in the platform data directory; set SKDECK_HOME to override it.
